# Call of Duty 4: Modern Warfare

[COD Options](cod-options.md) | [All guides](README.md)

Open **COD4** while the game is running. Follow the shared [statistics and player guidance](cod-options.md#statistics-and-profiles) before applying changes.

## Statistics

Multiplayer fields: prestige (up to 10), rank (up to 55), XP, score, kills, deaths, wins, losses, headshots, assists, hits, misses, best killstreak, and best win streak.

Statistics can be written but not read from the console here. Applying writes all fields. **Unlock All Challenges** and **De-rank Signed-In Profile** are available. This game does not have a custom-class-name editor.

## Game Options

- Match: Start Match, Restart Match, End Match, Leave Match, and Force Host.
- Host Settings: Unlimited Ammo, Jump Height, Gravity, and Game Speed.
- Vision: Default, Chrome, Cartoon, Rainbow, or No Fog.
- Profile: Clan Tag, up to four characters.
- Selected Player: Team (Allies, Axis, or Spectator), In-Game Name, and Message.

Refresh the player list before targeting a player. In-game names accept up to 15 characters and messages up to 80.
