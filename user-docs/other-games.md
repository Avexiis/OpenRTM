# Other Games

[All guides](README.md) | Requires a connected console

This page provides game-specific controls for:

- [Need for Speed: Most Wanted](nfsmw.md).
- [Need for Speed: Carbon](nfs-carbon.md).

Select the game that is actually running. Load the intended career before changing its values; enter free roam for controls that act on the current car or pursuit.

## Shared Controls

For cash or bounty, **Refresh** reads the current value. Enter an **Amount**, then use **Add**, **Remove**, or **Set**. Set replaces the current total; Add and Remove adjust it. Totals must stay between 0 and 2,000,000,000.

Move the **Heat** slider and click **Apply**. Its range is 1.0 to 5.0 in tenths.

Checkboxes apply immediately. Where shown, a nearby **Refresh** reads the current setting. Action buttons act immediately.

If the page says a value is unavailable in the current game state, return to the appropriate career/free-roam state before retrying. Do not assume the initial checkbox or number matches the running game until refreshed.

Keep a career backup. These are live game controls; normal game saving may preserve career-value changes.
