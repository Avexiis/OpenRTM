# Modern Warfare 2 (2009)

[COD Options](cod-options.md) | [All guides](README.md)

Open **MW2** while the original Modern Warfare 2 multiplayer is running.

## Statistics and Classes

Multiplayer fields: prestige (up to 10), XP, score, kills, deaths, assists, headshots, best killstreak, wins, losses, ties, and best win streak.

Statistics and ten custom class names can be read from the console before applying changes. **Unlock Selected Player** acts on the chosen player; **De-rank Signed-In Profile** still acts on the signed-in profile.

## Game Options

- Match: Start Match, Restart Match, End Match, Leave Match, and Force Host.
- Host Settings: Unlimited Ammo, Jump Height, Fall Damage, Gravity, Friction, Movement Speed, and Game Speed.
- Selected Player: Team (Allies, Axis, or Spectator), In-Game Name, and Message.
- Profile: Clan Tag, up to four characters.

Refresh the player list before using targeted controls. Names accept up to 15 characters and messages up to 80.

**Unfreeze Host Classes** and **Unfreeze Selected Player Classes** reset all of the target's custom class names to OpenRTM after confirmation. They are intended to recover from problematic class names, not to reset entire loadouts.

## GSC Menus

MW2 supports selecting source projects or compiled `.gscbin` files for injection, exporting compiled menus, batch compilation, and a source editor.

See [GSC Menus](gsc-menus.md) for injection and compiling multiple menus to a chosen folder, or [GSC Editor](gsc-editor.md) for project editing.
