# Bio Creator

[Gamer Profile](gamer-profile.md) | [All guides](README.md)

Open **Bio Creator** from Gamer Profile to compose a bio without losing fixed-width spacing.

Search the preset list, choose a design, and use **Load Preset**, or write your own. Categorized symbol buttons insert characters into the editor.

- **Copy** puts the current bio on the clipboard.
- **Use Bio** returns it to the loaded profile.
- **Clear** empties the editor.

The counter warns when the 499-character Xbox 360 bio limit is exceeded. **Use Bio** is unavailable while over the limit.

Returning a bio does not save the profile. Use **Save Changes** on Gamer Profile afterward.
