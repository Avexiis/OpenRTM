# Content Library

[All guides](README.md) | Requires a connected console

Content Library lists installed packages under the console's `Content` folder, with their owner, title, content type, file name, and size.

Click **Refresh Library** after connecting or changing installed content. Select a row and **Show Selected Path** to view its console location and IDs. Recognized owners and titles use friendly names.

## Install Packages

1. Choose **Install Packages** and select one or more package files, or drop them onto the page.
2. Wait for validation of the whole selection.
3. Let the upload finish before disconnecting.

OpenRTM chooses the destination owner, title, and content-type folders from each package. It verifies matching data already present and repairs or replaces incomplete or mismatched data.

Use [Game Saves](game-saves.md) first when a save needs a different profile assignment. Use [File Transfer](file-transfer.md) for arbitrary files, manual folder management, or downloads.
