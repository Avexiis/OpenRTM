# Black Ops II

[COD Options](cod-options.md) | [All guides](README.md)

Open **BO2** while Black Ops II is running. Choose controls for the current mode.

## Statistics and Classes

Multiplayer fields: prestige (up to 15), XP, unlock tokens, score, kills, deaths, assists, headshots, wins, losses, and time played.

Zombies fields: kills, deaths, downs, revives, hits, perks used, gibs, XP, and time played. Time fields use seconds.

Both statistics groups support **Read From Console**. Applying writes the whole selected group. **Unlock All Challenges** and **De-rank Signed-In Profile** are available for multiplayer.

Ten custom class names can be edited, but not read here.

## Game Options

- Match: Start Match, Restart Match, End Match, Leave Match, and Force Host.
- Host Settings: Unlimited Ammo.
- Selected Player: Message, up to 80 characters.
- Classes: Primary Weapon Camouflage, including standard patterns, Gold, and Diamond. Applying changes all ten primary-weapon camouflage slots.
- Zombies: Rank Emblem, with Bones, Crossed Bones, Skull, Skull with Knife, or Shotguns.
