# Home

[All guides](README.md) | Requires a connected console

Home displays the console's IP address, CPU key, signed-in gamertag, current title, console type, kernel version, console ID, SMC version, and temperatures. **Refresh Info** in the top row reads the information again.

Keep CPU keys and other console identity details private when sharing screenshots or logs.

## Console Controls

- **XNotify** sends a custom notification to the Xbox 360.
- Use **Warm Reboot**, **Cold Reboot**, or **Shutdown**.
- **DVD Eject** and **DVD Close** open or close the disc tray.
- **Screenshot to Clipboard** captures the console screen to the clipboard.

Save game progress before rebooting or shutting down. The console screenshot is separate from the capture-device screenshots on [Video Capture](video-capture.md).

## Dashlaunch Plugins

The plugin section loads and edits the console's five startup plugin slots. See [Dashlaunch Plugins](dashlaunch-plugins.md) for browsing, uploading, and saving plugin paths.

## Discord Rich Presence

When available, **Show Xbox Title As Discord Rich Presence (RPC)** shares the connected console's current title with Discord. Keep the desktop Discord app running.

The status refreshes every 30 seconds. Its elapsed timer restarts on a title change, and the status clears when the console disconnects or OpenRTM closes. Recognized titles show game names; otherwise, their title IDs are shown.

This is optional. Source builds need the [Discord setup](getting-started.md#optional-discord-setup) before the control becomes available.
