# Game Adder

[All guides](README.md) | Works offline

Game Adder adds game records to the profile currently open on [Gamer Profile](gamer-profile.md). It does not install games on the console.

1. Open the intended gamer profile.
2. Review its installed game records.
3. Search the bundled catalog by game name or title ID.
4. Select a title and click **Add Selected Game**.

The new record starts with locked achievements and zero earned gamerscore. A game already present cannot be added twice.

Adding a game writes the profile immediately, updates its totals, rehashes and re-signs it, and creates a `.bak` copy. Keep a separate original backup if making several edits. Use [Achievements](achievements.md) to edit unlocks and Gamer Profile to upload the resulting profile.
