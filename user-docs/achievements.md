# Achievements

[All guides](README.md) | Works offline

Open a gamer profile on [Gamer Profile](gamer-profile.md), then choose a game here. The list shows achievement names, descriptions, gamerscore, unlock status, and recorded times.

## Change Unlocks

1. Select one or more achievements.
2. Enable **Online unlock** to store an online unlock with a date and time, or leave it clear for an offline unlock without a timestamp.
3. Enter the date and time, or choose **Use Current Time** for the current local time.
4. Click **Apply Changes**.

Selecting an already unlocked achievement loads its existing unlock type and time so those details can be adjusted. This page does not provide a relock action. An online flag edits the local record; it does not perform an online unlock or upload by itself.

**Select All Locked** selects only unearned achievements. **Clear Selection** deselects rows, and **Refresh** reloads the displayed data.

Applying changes writes the profile, updates game/profile totals as needed, rehashes and re-signs it, and creates a `.bak` copy. Keep a separate original backup before multiple edits. Upload through Gamer Profile when ready.
