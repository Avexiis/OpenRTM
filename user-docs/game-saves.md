# Game Saves

[All guides](README.md) | Works offline

Game Saves changes the ownership assignments of supported Xbox and Xbox 360 save packages. It does not edit in-game values such as money, progress, or inventory.

Open a save with **Browse**, its file path, or drag and drop. Review the content type, title, package size, integrity status, and current profile, console, and device assignments.

## Assign and Save

Edit the assignment IDs, then choose:

- **Save, Rehash & Resign** to replace the loaded save.
- **Save As** to write another copy.

A `.bak` copy is enabled by default when replacing the loaded file. Keep an untouched original for recovery.

After saving an assignment, OpenRTM can remember it for later use. Open the matching profile once on [Gamer Profile](gamer-profile.md) so its gamertag can be recognized. Choose that gamertag from **Profiles** to fill the saved assignment IDs.

Saved assignments are labeled by the detected gamertag, not a custom name. Selecting an assignment fills the fields; save the file to apply it.

Use [Content Library](content-library.md) to install the reassigned package or [File Transfer](file-transfer.md) for manual copying.
