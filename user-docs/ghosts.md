# Ghosts

[COD Options](cod-options.md) | [All guides](README.md)

Open **Ghosts** while the game is running. Use the statistics group matching the current mode.

## Statistics and Classes

Multiplayer fields: prestige (up to 10), rank XP, squad points, score, kills, deaths, best killstreak, hits, misses, wins, losses, games played, and time played in seconds.

Extinction fields: prestige (up to 25), teeth, revives, kills, and score.

Both groups support **Read From Console**. Ten custom class names also support reading and editing. **Unlock All Challenges** and **De-rank Signed-In Profile** are available for multiplayer.

## Game Options

- Match: Start Match, Restart Match, End Match, Leave Match, and Force Host.
- Host Settings: Unlimited Ammo, Jump Height, Fall Damage, Gravity, Friction, Movement Speed, and Game Speed.
- Selected Player: In-Game Name and Message.

Refresh the player list before targeting a player. Names accept up to 15 characters and messages up to 80.
