# COD Options

[All guides](README.md) | Requires a connected console, except GSC editing/compilation

Select the tab matching the running Call of Duty game. Controls are grouped into statistics, custom classes where supported, game options, and MW2 GSC menus.

Use these controls in your own private sessions. Host settings require the appropriate host/game state, and Zombies or other mode-specific options must be used in that mode. Selecting a tab does not launch or switch the game.

## Statistics and Profiles

**Read From Console**, where available, fills the statistics with current values. **Apply Statistics writes every field in that group**, including fields left at zero. Read first, or supply all intended values when reading is unavailable.

**Unlock All Challenges** affects the signed-in profile. MW2 instead offers **Unlock Selected Player**, which uses the player selection.

**De-rank Signed-In Profile** resets rank and prestige after confirmation. It affects the signed-in profile regardless of the target player. Other statistics may also be reset by the game's reset operation. Keep a profile backup before changing statistics or unlocks.

## Classes and Players

Where a **Custom Class Names** page is available, fill the names and choose **Apply Class Names**. Read the current names first when **Read From Console** is offered; applying sends all displayed names.

The target player selector affects controls labeled for the selected player, not ordinary profile statistics. **Refresh Players**, where available, reads the current player list. Refresh after players join or leave.

Match buttons act immediately. Checkboxes apply when changed; choice, number, and text settings use their adjacent **Apply** controls. Text fields enforce their supported length.
