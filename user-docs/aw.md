# Advanced Warfare

[COD Options](cod-options.md) | [All guides](README.md)

Open **AW** while Advanced Warfare is running. Exo Zombies controls are separate from multiplayer settings.

## Statistics and Classes

Multiplayer fields: prestige (up to 30), rank XP, score, kills, deaths, assists, accuracy, wins, losses, captures, confirms, best killstreak, games played, time played in seconds, and suicides.

Statistics and ten custom class names support **Read From Console** and editing. **Unlock All Challenges** and **De-rank Signed-In Profile** are also available.

## Game Options

- Match: Start Match, Restart Match, End Match, Leave Match, and Force Host.
- Host Settings: Unlimited Ammo, Jump Height, Movement Speed, and Game Speed.
- Selected Player: No Friction, In-Game Name, and Message.
- Exo Zombies: Ragdoll Gravity, Jump Height, Movement Speed, and Game Speed.

Refresh the player list before targeting a player. Names accept up to 15 characters and messages up to 80.
