# Black Ops

[COD Options](cod-options.md) | [All guides](README.md)

Open **BO1** while Black Ops is running. Use the controls for the active mode.

## Statistics and Classes

Multiplayer fields: prestige (up to 15), XP, score, kills, deaths, assists, headshots, wins, losses, COD Points, and time played in seconds.

**Read From Console** is available for statistics. Applying writes all fields. **Unlock All Challenges**, **De-rank Signed-In Profile**, and editing ten custom class names are available. Class names are write-only here.

## Game Options

Match controls provide Start Match, Restart Match, End Match, Leave Match, and Force Host.

**Message** sends up to 80 characters to the selected player.

## Zombies

Zombies has its own Force Host and Unlimited Ammo controls, plus **Skip Current Round**. Set **Points** for the selected player or **Round** from 1 to 255 for the session.
