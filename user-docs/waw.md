# World at War

[COD Options](cod-options.md) | [All guides](README.md)

Open **WAW** while World at War is running. Use multiplayer controls in multiplayer and Zombies controls in a Zombies session.

## Statistics and Classes

Multiplayer fields: prestige (up to 10), XP, score, kills, deaths, best killstreak, headshots, and time played in seconds. These fields are write-only here; applying sends every field.

**Unlock All Challenges**, **De-rank Signed-In Profile**, and editing five custom class names are available. Existing class names cannot be read here.

## Game Options

- Match: Start Match, Restart Match, End Match, Leave Match, and Force Host.
- Host Settings: Unlimited Ammo, Jump Height, Gravity, and Game Speed.
- Vision: Default, Chrome, Cartoon, Rainbow, or No Fog.
- Selected Player: Message, up to 80 characters.

## Zombies

Use Next Round, Previous Round, Turn On Power, Double Points, or Revive All for the session. You can also set the round from 1 to 255.

Give All Perks and Give Points target the selected player. Zombies Prestige accepts 0 to 10, and Zombies Name accepts up to 15 characters for that player.
