# Modern Warfare 3

[COD Options](cod-options.md) | [All guides](README.md)

Open **MW3** while the game is running. Multiplayer and Special Ops statistics are separate groups.

## Statistics and Classes

Multiplayer fields: prestige (up to 20), XP, score, kills, deaths, assists, headshots, best killstreak, K/D ratio, wins, losses, ties, best win streak, hits, misses, accuracy, prestige tokens, time played, double XP time, and double weapon XP time.

K/D is entered multiplied by 1,000; accuracy is entered multiplied by 100. Time fields use seconds.

Special Ops / Survival fields: rank XP, kills, juggernaut kills, headshots, hits, misses, and waves survived.

Both groups support **Read From Console**. Fifteen custom class names also support reading and editing. **Unlock All Challenges** and **De-rank Signed-In Profile** are available for multiplayer.

## Game Options

- Match: Start Match, Restart Match, End Match, Leave Match, and Force Host.
- Host Settings: Unlimited Ammo, Jump Height, Fall Damage, Gravity, Friction, Movement Speed, and Game Speed.
- Selected Player: Team (Allies, Axis, or Spectator), In-Game Name, and Message.

Refresh the player list before targeting someone. Names accept up to 15 characters and messages up to 80.
