# Need for Speed: Most Wanted

[Other Games](other-games.md) | [All guides](README.md)

Select Most Wanted while the Xbox 360 game is running. Load your career; enter free roam before pursuit, car, or travel actions.

| Section | Controls |
| --- | --- |
| Career | Refresh, add, remove, or set Cash and Bounty; Skip New Career Intro. |
| Pursuit | Heat from 1.0 to 5.0, Cops enabled/disabled, Start Pursuit, and Prevent Bust. |
| Driving | Infinite Speedbreaker, Infinite Nitrous, and Freeze Opponents. |
| Visual | Hide or restore the Yellow Filter. |
| Fast Travel | Safe House and Car Lot. |

Use the [shared controls](other-games.md#shared-controls) for applying amounts and heat. Skip New Career Intro applies when starting a new career; it is not a general cutscene-skip button.

Fast Travel changes your current game location. Save progress before travel or changing career values. Disable temporary driving/visual changes when finished using them.
