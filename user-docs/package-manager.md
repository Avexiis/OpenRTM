# Package Manager

[All guides](README.md) | Works offline

Open a CON, LIVE, or PIRS Xbox 360 package with **Browse**, its file path, or drag and drop.

The page displays metadata, assignment IDs, integrity status, package/title images, a suggested console destination, and the files inside the package.

## Inspect or Edit

CON packages support editing display name, title name, description, publisher, title ID, profile assignment, console ID, device ID, and both images.

Use the image **Replace** controls to choose replacements, or **Export** to save the displayed images.

**Save, Rehash & Resign** updates the loaded file; **Save As** writes a separate copy. Creating a `.bak` copy when replacing the loaded file is enabled by default. Keep a separate untouched backup before repeated edits.

LIVE and PIRS packages are read-only: their metadata and contents can be inspected or exported, but their original signatures cannot be recreated.

## Extract and Install

Select an entry in **Package Files** and click **Extract Selected File** to save that internal file.

This page does not install packages. Use [Content Library](content-library.md) to place packages on the console, or [Game Saves](game-saves.md) for reusable save assignments.
