# Black Ops III

[COD Options](cod-options.md) | [All guides](README.md)

Open **BO3** while Black Ops III is running. Multiplayer and Zombies settings must be used in the matching mode.

## Statistics and Classes

Multiplayer fields: prestige (up to 11), rank XP, score, kills, deaths, assists, headshots, team kills, suicides, wins, losses, ties, current win streak, hits, misses, total shots, and time played.

Zombies fields: prestige (up to 11), rank (up to 35), rank XP, score, kills, deaths, rounds survived, perks used, and time played. Time fields use seconds.

Both groups are write-only here. **Apply Statistics** sends every field, including zeros. **Unlock All Challenges** and **De-rank Signed-In Profile** are available for multiplayer.

Ten custom class names can be set, but not read. **Applying these names also resets the public and custom multiplayer loadouts to the default assault setup.** Back up or record your loadouts first.

## Game Options

- Match: Start Match, Restart Match, End Match, Leave Match, and Force Host.
- Host Settings: multiplayer Jump Height.
- Zombies: Restart Match and Jump Height.
- Selected Player: Refill Multiplayer Ammo, Refill Zombies Ammo, Multiplayer Message, and Zombies Message.

Choose the right player and mode before using refill or message controls. Messages accept up to 80 characters.
